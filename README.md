Score the Sale before it ships

CIMET CRM QA Automation is a Streamlit-based prototype that automatically evaluates CRM sales against retailer-specific QA checks before submission. It analyzes call transcripts against predefined verbatim, factual, and behavioural checks, provides evidence for each result, identifies critical failures, and applies an automated AUTO-SUBMIT / HOLD gate to reduce manual QA effort and prevent unscored or non-compliant sales from proceeding.
